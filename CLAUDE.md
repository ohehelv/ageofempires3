# Колонии Нового Света — заметки для работы над кодом

Браузерная 3D RTS в духе Age of Empires III. Чистый JS + Three.js r149 (UMD с jsDelivr), без фреймворков и бандлера. Итог сборки — один HTML-файл `dist/index.html`. Он же публикуется как артефакт claude.ai: https://claude.ai/artifact/B62bVaUV2kpoydhB741AKf (обновлять публикацией с этим `url`). Все тексты в игре и общение с владельцем — на русском.

## Сборка

- `npm run build` (`node build.mjs`) склеивает `src/*.js` **по алфавиту** (01…16) в одну IIFE со `'use strict'` и дописывает после `shell.html` (вся разметка и CSS) и тега three.js. Пишет `dist/game.js`, `dist/index.html`, `dist/kolonii.html`.
- Модулей ES нет: никаких import/export, всё — объявления верхнего уровня внутри одной IIFE. Имена уникальны на весь проект. Порядок файлов = порядок объявлений: код верхнего уровня файла видит только то, что объявлено в предыдущих файлах (функции и методы, вызываемые позже, видят всё).
- Внутри JS нельзя писать строку `</script` — сборка упадёт.

## Ключевые принципы

- **Симуляция отделена от графики.** Файлы 01, 02, 04, 05, 06, 10, 11, 12 загружаются в Node без браузера (`test/sim*.cjs`). В них нельзя обращаться к DOM, `UI`, `RS`, `FX` напрямую: графика узнаёт о событиях через `game.fx(...)` (проверяет наличие `FX`) и `game.emit(...)`. 06 нужен симуляции ради `linColor`, поэтому код верхнего уровня в нём не должен требовать WebGL.
- Фиксированный тик `TICK = 0.05` с (20 Гц), рендер интерполирует `px/pz/ph → x/z/heading`.
- Логика использует только `game.rng`; `Math.random` — лишь в визуальных эффектах.
- Параметры баланса живут в `02_data`, поведение читает их оттуда.
- Ресурс «носить не нужно»: сбор сразу идёт в запас игрока (`Player.gain`), опыт `XP_PER_RES` за единицу.
- Горячие клавиши панели команд — по сетке `QWERT / ASDFG / ZXCVB` (слоты 0–14). Поселенец: дом 0, мельница 1, рынок 2, застава 3, плантация 4, казармы 5, конюшня 6, церковь 7, литейный двор 8, арсенал 9, торговый пост 10, бастион 11, атака с ходу 12, укрыться 13, стоп 14. Рынок: технологии 0–6, купить 7–9, продать 10–12.
- HUD по умолчанию внизу (у владельца верх страницы в окне просмотра перекрыт); вариант «сверху» — в меню паузы (`UI.setHudLayout`). `IntersectionObserver` на `#vis-probe` выставляет `--clip-top/--clip-bottom`, если фрейм выше видимой области.

## Как добавить

**Юнит:** запись в `UNITS` (теги `cls`, `cost`, `at`, `age`, `model`, `hotkey`) → модель в `unitModel` (07) или повторное использование → ключ в списке `unitKeys` в `renderIcons` (09) → здание в `BUILDINGS[…].trains` → вес в `BotAI.pickUnit` (12).

**Здание:** запись в `BUILDINGS` (размер кратен 2 м, `cost`, `age`, при необходимости `attack`/`trains`/`techs`) и в `VILLAGER_BUILDS` → `buildingModel` (07) → слот в `buildCommands` (15) → решение о постройке в `BotAI.handleBuildings` (12). Атака зданий: `Building.update` → `Game.buildingShot` (`proj: 'cannon'` — ядро со сплэшем, иначе мгновенный выстрел).

**Технология:** запись в `TECHS` (`at`, `age`, `cost`, `fx`, `icon`) и в `techs` здания; новый вид `fx` обрабатывается в `Player.applyFx`; порядок изучения ботом — `handleTechs`.

**Ресурс** (так добавлялся камень): `RES` и словари названий/подсказок в 02 → ключ скорости в `GATHER` и `Player.mods.gather` → `Player.res`, `stats.gathered` → месторождения в генераторе карты → `Resource` (`res`, `rateKey`, `deposit`) → `Game.init`, `depleteResource`, `findBuildSpot` → модель в `propGeo`, инстансы в `RS.init`, иконка в `renderIcons` → пиктограмма в `Glyph.draw` → строка `#r-<ресурс>` в `shell.html` → `desired/assignGather/handleMarket` у бота.

## Тесты и проверка

- `npm test` — сборка, `node --check dist/game.js`, короткая партия ботов.
- `npm run sim` / `sim:ffa` / `sim:balance` — партии ботов без графики, раз в минуту печатают состояние каждого игрока. Норма: средний тик меньше 1 мс, без длинных простоев поселенцев (`idle`), боты доходят до III–V эпох.
- Профилирование: `node --cpu-prof test/sim.cjs 16 2 hard`. `findPath` не должен доминировать — если доминирует, кто-то бесконечно ищет путь к недостижимой цели.
- `node test/run.cjs <сценарий>` — Chromium (Playwright, SwiftShader) открывает `dist/kolonii.html` и выполняет `test/actions/<сценарий>.js`, скриншоты — в `test/*.png`. Из теста доступны `window.__nw` (`App`, `game`, `UI`, `Input`, `Cam`, `GFX`, `RS`, `FX`, `Sfx`), `window.__nwGlyph`, `window.__nwBot`. В SwiftShader кадр идёт около секунды — логику крутите через `game.tick()` в `page.evaluate`.
- Перед публикацией: `npm test` → `npm run sim` → `npm run test:hud` и `test:flows` → посмотреть скриншоты.

## Подводные камни, на которые уже наступали

- three r149: один материал на `InstancedMesh` с `instanceColor` и без него не переключает шейдер → отдельные материалы `staticInst` и `staticInstC`.
- Поиск пути дорогой: на тик есть бюджет (`pathBudget`, `pathNodes`). Недостижимые цели должны быстро отбрасываться (`treasure.noPath`, `Resource.unreachable`), иначе средний тик вырастает в разы.
- Генератор карты гарантирует связность: к сокровищам, стадам и месторождениям прорубается коридор в лесу (`carveTo`), недостижимые удаляются. Сокровища не ставятся ближе 20 м к гнёздам торгового пути и 10 м к дороге — стража убивала исследователя на стройке поста.
- Ящики и сокровища блокируют стройку (`Game.canPlace`), иначе бот закрывал ящик домом и его поселенцы зависали.
- Поселенцы, разобравшие ящики, переходят к ягодам или лесу (`Unit.findNextResource`).
- Ограничения артефакта claude.ai: скрипты только с cdnjs/jsdelivr/unpkg (версия указана точно), CSS — только Google Fonts; без `alert/confirm/prompt`; `localStorage` только в `try/catch`; звук — после первого жеста пользователя.
